## ADDED Requirements

### Requirement: Working artifacts are preserved but non-authoritative
Project layout validation SHALL permit controlled work and staging evidence to remain in the project while excluding it from accepted model authority, source identity, and release projections.

#### Scenario: Working cache exists
- **WHEN** generated bytecode or a classified work artifact is present under the governed project work area
- **THEN** its bytes remain untouched, it does not block layout currentness or change source identity, and publication excludes it

#### Scenario: Unknown governed source is present
- **WHEN** an unclassified governed source or unsafe reparse point appears
- **THEN** the layout gate blocks before applying any working-artifact exclusion
