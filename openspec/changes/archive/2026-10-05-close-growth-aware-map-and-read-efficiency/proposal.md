## Why

Normal functional tasks currently omit real finite software-growth observations and may terminate before exposing an independently readable diagnostic. Invocation-local caches do not cover the entire evidence chain, so repeated reads and late interface failures still delay maintenance despite successful affected-native reuse.

## What Changes

- Carry declared finite path changes and original growth evidence through normal task production, public read and one independent end guard.
- Publish authenticated, receipt-free diagnostics for insufficient tasks, preserving their original stopping reason, first gap and next owner.
- Add precise current action locations and a compact current/target/gap/unknown understanding projection without claiming universal optimal architecture.
- Share original bytes and complete validated typed state inside one invocation; authenticate only selected native leaf material for ordinary tasks; prepare transport lanes once per batch.
- Model three concrete normal-use responsibilities using the existing two normative owners and preserve all original goals and accepted lineages.
- Parameterize private maintenance controllers, perform inexpensive interface checks before stable qualification, and retain independent final verification, publication and installation obligations.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- `task-aware-functional-map`: add finite growth transport, authentic insufficient-task diagnostics, exact action detail and invocation-local read efficiency.
- `context-indexed-architecture-direction`: make the normal task producer's current-or-original-gap outcome explicit and retain bounded contextual architecture judgments.

## Impact

Affected public implementation includes functional task context/read, model authority storage, model path quality and public read transport. Native declarations and finite implementation inventory change only for the authoritative-model-system and model-maturation-loop responsibilities named in the design. Existing normative goals, unknown states, protected failures, full typed authority and exact proof freshness remain enforced. No PlanningTool changes, compatibility readers, arbitrary cost ceilings, global watcher, global architecture rewrite or new per-test reuse authority are included.
