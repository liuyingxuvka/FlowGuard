## ADDED Requirements

### Requirement: Non-trivial code work exposes two independent decisions
The compact FlowGuard AI entry SHALL separately expose model sufficiency and execution authorization, plus allowed scope, open gaps, required validation, and typed next owner actions for non-trivial code work.

#### Scenario: Scoped authorization is not displayed as full understanding
- **WHEN** implementation is admitted with open gaps
- **THEN** the summary MUST display ready-scoped authorization and the unchanged non-full maturation decision as separate values

### Requirement: Sufficiency coordination adds no public route
The compact entry SHALL coordinate current preflight, maturation, admission, structure, risk, and closure owners without adding a public understanding, readiness, or authorization skill or alias.

#### Scenario: Public route topology is inspected
- **WHEN** the upgraded skill suite is validated
- **THEN** the public FlowGuard route set MUST remain unchanged and lightweight or read-only work MUST still skip unrelated deep routes with a reason
