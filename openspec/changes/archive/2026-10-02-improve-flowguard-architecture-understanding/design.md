## Risks / Trade-offs

- Self-consistent declaration can omit software behavior → preserve declared/scoped confidence until the existing independent inventory and reverse-binding owners verify the exact source boundary.
- Similar labels or duplicate hashes can manufacture equivalence → require independent semantic content, finite overlapping context and current original native conformance.
- Receipt/declaration circularity can invalidate provenance → derive admitted evidence after immutable terminal production, never backfill raw declaration.
- Source-goal change can invalidate prior evidence → invalidate exact consuming owner/topology closure and preserve missing or conflicting complete scope.
- Currentness may drift during parallel implementation → freeze only after all named writers and the mapping compiler stabilize; final qualification stays with the single declared integration owner.
