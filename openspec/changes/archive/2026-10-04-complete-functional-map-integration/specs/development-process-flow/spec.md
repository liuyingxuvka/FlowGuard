## ADDED Requirements

### Requirement: Functional completion and delivery boundaries
Ordinary work SHALL finish at its declared functional evidence boundary without an implicit operation or time budget. Explicit supervision and finite full-validation authorization SHALL remain effective. Publication and local installation SHALL each require their own current verification.

#### Scenario: Implementation checks complete
- **WHEN** implementation checks complete
- **THEN** Implementation completion does not imply full validation, GitHub publication or local installation completion.
