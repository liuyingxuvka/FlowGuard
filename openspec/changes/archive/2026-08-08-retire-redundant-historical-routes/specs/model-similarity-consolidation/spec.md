## REMOVED Requirements

### Requirement: Model signatures
**Reason**: Standalone similarity signatures duplicate canonical blueprint, BCL, and topology identities.
**Migration**: Derive typed relation endpoints from current canonical owners.

### Requirement: Maintenance groups
**Reason**: Maintenance groups duplicate the affected-model set.
**Migration**: Use exact affected topology.

### Requirement: Change impact obligations
**Reason**: Affected topology and the consuming owner now generate exact obligations.
**Migration**: Bind obligations directly to the current owner.

### Requirement: Shared and variant test obligations
**Reason**: Model-Test Alignment and ContractExhaustion own test obligations.
**Migration**: Materialize cases and tests under those owners.

### Requirement: Code maintenance obligations
**Reason**: CodeStructure and ArchitectureReduction own code dispositions.
**Migration**: Bind the typed relation to the relevant code owner.

### Requirement: Typed model relation classification
**Reason**: Replaced by the smaller canonical relation requirement in this delta.
**Migration**: Consume canonical endpoint and relation identities without standalone review state.

### Requirement: Evidence-gated recommendations
**Reason**: The consuming canonical owner gates its own decision.
**Migration**: Attach relation provenance to that owner's evidence.

### Requirement: Downstream FlowGuard route handoffs
**Reason**: The relation is already an input to the selected owner and needs no separate route handoff layer.
**Migration**: Invoke the exact owner directly.

### Requirement: No automatic rewrite
**Reason**: The standalone engine is removed; canonical owners already prohibit unproved rewrites.
**Migration**: Follow the selected owner's mutation boundary.

### Requirement: Public template and CLI
**Reason**: The standalone product route is retired.
**Migration**: Use target blueprint/preflight plus the exact consuming owner.

### Requirement: Model signatures carry reusable risk depth
**Reason**: Risk depth belongs to the model and ContractExhaustion, not a duplicate signature.
**Migration**: Bind finite risk dimensions to the canonical model.

### Requirement: Business path identity participates in similarity classification
**Reason**: BCL owns business-path identity directly.
**Migration**: Use exact commitment and path identities as relation sources.

### Requirement: Business path evidence appears in similarity output
**Reason**: There is no standalone similarity report after contraction.
**Migration**: Preserve the source identities on the typed relation and consuming result.

### Requirement: Similarity compares materialized exact-intent identities
**Reason**: Canonical DNA and BCL already own exact intent identities.
**Migration**: Compare or connect identities only inside the consuming owner.

### Requirement: Similarity handoffs materialize downstream obligations
**Reason**: The consuming owner now materializes its own obligations directly.
**Migration**: Preserve relation provenance on canonical cases or reduction candidates.

### Requirement: Model signatures include behavior plane
**Reason**: Behavior plane is already part of canonical ownership identity.
**Migration**: Carry plane identity on the relation endpoint where relevant.

### Requirement: Cross-plane language is false-friend evidence
**Reason**: False-friend classification belongs to exact ownership/preflight decisions.
**Migration**: Record cross-plane evidence on the consuming owner without a separate similarity engine.

### Requirement: Similarity handoff preserves plane evidence
**Reason**: Replaced by minimal typed relation provenance.
**Migration**: Preserve plane identity with the relation endpoint and consuming result.
